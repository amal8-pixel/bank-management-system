
Bank Management System
A simple bank management system built with Python to practice and demonstrate Object-Oriented Programming (OOP) concepts.
Features
• Create savings and checking accounts.
• Check account balance.
• Withdraw money with balance validation.
• Apply a withdrawal fee to checking accounts.
• Calculate interest for savings accounts.
• Display account information.
OOP Concepts
This project demonstrates the following concepts:
• Classes & Objects: Creating bank account objects.
• Encapsulation: Protecting account balance using a private attribute.
• Inheritance: Reusing shared functionality through a parent class.
• Polymorphism: Implementing different withdrawal behaviors.
• Abstraction: Defining a common account structure using an abstract class.
• Method Overriding: Customizing withdrawal behavior in the checking account.
Technologies
• Python 3
• Object-Oriented Programming (OOP)
